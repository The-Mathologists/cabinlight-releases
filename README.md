# CabinLight

Menu bar call lights for The Mathologists team.

**Download:** [CabinLight.dmg](https://github.com/The-Mathologists/cabinlight-releases/releases/latest/download/CabinLight.dmg)

1. Open the downloaded `CabinLight.dmg`.
2. Drag **CabinLight** into **Applications**.
3. Open CabinLight from Applications, enter your name and the team code.

CabinLight keeps itself up to date — you never need to download it again.

_This repository only hosts the app downloads and the update feed (`appcast.xml`)._
